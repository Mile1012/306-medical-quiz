# 306 西综日常刷题

移动端友好的静态刷题网页，内置 1988-2026 年 306 西综题库。

站点入口：https://mile1012.github.io/306-medical-quiz/

## 功能

- 189 个教材章节练习卷
- 39 个历年真题卷
- A、B、U 型题单选
- X 型题完整多选判分
- 错题回顾、收藏、笔记和浏览器本地进度
- 可选 OpenAI 兼容接口生成题目解析

浏览器数据保存在各设备本地，电脑和手机之间不会自动同步。
